# TLDR

Notes regarding working with the YouTube Data API

## Setting up the YouTube Data API key

- Sign up for `cloud.google.com`
- Go to `console.cloud.google.com`
- Create a project called `Content Ideation`
- Enable the following APIs
    - `YouTube Data API v3`
        - console.cloud.google.com/apis/library/youtube.googleapis.com
- Go to `https://console.cloud.google.com/apis/credentials`
- Create an "API key" cred
    - Call it `content-ideation`
    - Restrict it to the "YouTube Data API v3"
